# Geography_HS

高中地理知识库 — 覆盖人教版 2019 全册教材 + 2012-2026 高考地理真题。

> ⚠️ 本站参考答案均为原创编写，仅供学习教育用途。

## 内容规模

| 类别 | 数量 |
|------|------|
| 知识点 | 74（自然 26 / 人文 14 / 区域 14 / 世界中国 12 / 工具 8） |
| 高考真题 | 2012-2026，全国卷 + 主要省份 |
| 覆盖教材 | 必修第一/二册、选择性必修第一/二/三册 |

## 快速开始

```bash
npm install
npm run build:scripts
npm run build
npm run dev
```

## 技术栈

- Astro 5.x — 静态站点生成
- Tailwind CSS — 样式
- Vitest — 测试
- TypeScript — 构建脚本
- GitHub Pages — 部署

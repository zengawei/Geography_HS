# 高中地理知识点深度优化方案

> 创建日期：2026-09-03
> 状态：执行中

## 背景

之前已通过 Python 脚本对全部 74 个知识点进行了批量扩展，但内容较为表面，存在以下不足：
- key_concepts 缺乏概念辨析和易错陷阱
- 缺少 Markdown 表格对比
- description 过于简短，缺乏底层逻辑分析
- common_mistakes 格式不统一，缺少 ❌/✅ 对照
- 缺少答题模板和典型案例

以 `agricultural-location.json` 为质量标杆，需要将同等深度推广到所有知识点。

## 核心原则

1. **不生搬硬套**：每个知识点有自身的知识结构和考试特点，需个性化设计
2. **Python 脚本批量生成**：不使用 Agent，用 Python 脚本承载深思熟虑的内容
3. **分批执行**：每批 10-15 个知识点，验证后再进行下一批
4. **质量对标**：达到 agricultural-location.json 的水平

## 质量标杆（agricultural-location.json 特征）

- **description**：600+ 字，含概念辨析、关键概念区分、底层逻辑
- **key_concepts**：7 个，覆盖概念辨析、自然因素详解、社会经济因素详解、动态变化、典型案例、答题模板、易错陷阱
- **Markdown 表格**：4 个以上对比表格
- **common_mistakes**：6 个，统一 ❌/✅ 格式
- **考试导向**：选择题高频坑、综合题答题模板

## 三阶段执行计划

### 第一阶段：评估与分类（当前）

1. 扫描所有 74 个 KP 文件
2. 按考试频率（high/medium/low）和类别（natural/human/regional/tools/world_china）分类
3. 评估每个 KP 当前质量（description 长度、key_concepts 数量、有无表格、common_mistakes 质量）
4. 确定优先级排序
5. 为不同类型 KP 设计优化模板

### 第二阶段：分批深度优化

按批次用 Python 脚本生成优化后的 JSON 文件：
- 每批 10-15 个 KP
- 每个 KP 根据类型和考试特点个性化设计
- 每批完成后 build 验证
- 预计 5-7 批完成全部优化

### 第三阶段：验证与迭代

1. 全量 build 测试
2. 抽查各类型页面效果
3. 检查 JSON schema 验证
4. 迭代修正

## 优化模板设计（按类别）

### 自然地理类
- 侧重：原理机制、过程分析、图表判读
- 必备：原理示意图描述、过程对比表格、因果链分析

### 人文地理类
- 侧重：区位分析、因素评价、动态变化
- 必备：因素对比表格、答题模板、典型案例

### 区域地理类
- 侧重：区域特征、问题诊断、治理措施
- 必备：区域对比表格、问题分析框架、治理措施模板

### 工具类
- 侧重：使用方法、判读技巧、计算应用
- 必备：操作步骤、判读要点表格、常见错误

### 世界与中国地理类
- 侧重：空间分布、区域差异、综合分析
- 必备：分布规律表格、区域对比、综合分析模板

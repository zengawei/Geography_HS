# Geography_HS — 高中地理知识库需求文档

> 版本：v1.2（评审后修订）
> 日期：2026-08-31

## 1. 项目背景

### 1.1 目标

构建一个覆盖人教版高中地理全册教材 + 2012—2026 年高考地理真题的静态知识库网站，帮助学生系统学习地理知识、按知识点/教材章节/高考真题三个维度进行检索和练习。

### 1.2 参考项目

本项目参考 [pep-math](https://github.com/zengawei/pep-math)（高中数学知识库）的工程架构，沿用其 TDD、ADR、Conventional Commits、构建脚本自动化等工程实践。但地理学科与数学存在显著差异，本项目在内容模型、知识体系、页面设计等方面做了针对性调整（详见第 2 节）。

### 1.3 技术栈（初步）

| 技术 | 用途 |
|------|------|
| Astro 5.x | 静态站点生成 |
| Tailwind CSS | 样式 |
| Vitest | 测试 |
| TypeScript | 构建脚本 |
| GitHub Pages | 部署托管 |

> **与 pep-math 的差异**：地理不涉及大量数学公式，暂不需要 KaTeX。但可能需要图表/示意图支持（见第 2 节讨论）。

## 2. 地理学科与数学学科的关键差异

> 本节明确地理学科的独特性，说明为何不能直接照搬 pep-math 的设计。

### 2.1 差异总览

| 维度 | 数学 | 地理 | 对本项目的影响 |
|------|------|------|--------------|
| **核心思维** | 抽象逻辑、公式推导 | 空间思维 + 区域认知 | 知识点体系完全不同，需独立设计 |
| **表达形式** | 公式、符号、证明 | 地图、示意图、图表、数据、文字 | 题目中大量引用地图/图表，需专门处理 |
| **知识组织** | 按教材章节线性递进 | 自然地理 + 人文地理双主线，交叉融合 | 知识图谱更复杂，需支持跨领域关联 |
| **教材版本** | 人教 A 版 2019 统一 | 多版本并存（人教版、湘教版、中图版、鲁教版） | v1 仅覆盖人教版 2019，但知识点设计应兼容其他版本 |
| **高考命题** | 全国统一 / 新高考统一 | 全国卷 + 各省自主命题并存，且地理在旧高考中属文综一部分 | 试卷分类更复杂，需处理文综卷中的地理部分 |
| **选做题** | 无 | 旧高考有选修模块选做题 | 需额外处理选做题的录入和展示 |
| **公式需求** | 大量（KaTeX 必须） | 极少（仅少量计算如时区、太阳高度角） | 暂不引入 KaTeX，必要时用纯文本或轻量标记 |
| **课后习题** | 每节有固定习题，逐题录入 | 教材以"活动""思考""案例"为主，非标准习题格式 | 课后内容以"活动/案例"形式呈现，不强求逐题结构化 |

### 2.2 地图与图表处理策略（v1 支持 SVG）

地理题目中大量引用地图、示意图、统计图表。这是与数学最大的差异。

**v1 决策：支持内联 SVG**

| 类型 | 处理方式 | 说明 |
|------|---------|------|
| **示意图/剖面图** | SVG 内联（`public/svg/` 存放，Markdown 引用） | 如地球光照图、地质剖面图、大气环流图 |
| **统计图表** | SVG 图表 + Markdown 表格辅助 | 如气温降水柱状图、人口金字塔 |
| **区域地图** | SVG 简图 + 关键标注 | 如等高线地形图、区域位置图 |
| **数据图** | SVG 折线图/柱状图 + 文字补充 | 如 GDP 变化趋势图 |
| **复杂原图** | SVG 简化版 + 文字描述关键信息 | 无法 1:1 复刻的复杂地图，提取核心要素 |

**SVG 规范**：
- SVG 文件存放在 `public/svg/` 目录，按知识点或年份分子目录
- 文件命名：`{知识点ID}-{描述}.svg` 或 `{year}-{paper}-{qNum}.svg`
- 题目 md 文件中通过 `![描述](/svg/path/to/file.svg)` 引用
- SVG 应为纯矢量图形，**禁止嵌入 `<image/>` 位图**（构建脚本自动校验）
- 每个 SVG 必须包含 `<title>` 元素作为无障碍描述
- 颜色使用 CSS 变量或当前颜色值（`currentColor`），**禁止硬编码固定色值**（确保暗色模式兼容）
- 单个 SVG 文件大小上限 **200KB**（超出需简化路径或拆分）
- 禁止直接复刻教材原图，应重新绘制简化示意图（版权考量）

> ⚠️ SVG 录入成本较高。对于简单图表（数据表格、简单示意图），优先用 SVG；对于极其复杂的原图（如高分辨率卫星图），可用文字描述 + SVG 简化版替代。录入人员需根据题目实际需求判断。

### 2.3 课后内容的差异化处理

数学教材每节有明确的"练习 A/B"、"习题"，pep-math 逐题结构化录入。地理教材的内容组织不同：

| 数学（pep-math） | 地理（本项目） |
|-----------------|--------------|
| 练习 A（基础题） | "思考"（课堂讨论题，开放性强） |
| 练习 B（提高题） | "活动"（探究性活动，通常需小组合作） |
| 章末复习题 | "案例"（案例分析，综合性强） |
| | "问题研究"（课题研究） |

**v1 决策**：

- 教材课后内容不作为 v1 核心范围（与 pep-math 不同）
- v1 聚焦于：**知识点体系** + **高考真题**
- 课后"活动""思考""案例"作为 v2 扩展内容
- 原因：地理的"活动"和"案例"开放性很强，结构化难度大，且高考真题已覆盖核心考点

## 3. 数据范围

### 3.1 教材覆盖

基于 **人教版 2019 版**（2017 课标），共 5 册：

| 册别 | 全称 | 主要内容 |
|------|------|---------|
| 必修第一册 | 必修一 | 宇宙中的地球、地球上的大气、地球上的水、地貌、植被与土壤 |
| 必修第二册 | 必修二 | 人口、城镇、农业、工业、交通运输、服务业 |
| 选择性必修一 | 选必一 | 地球的运动、自然环境中的物质运动和能量交换、自然环境的整体性与差异性 |
| 选择性必修二 | 选必二 | 区域发展、资源环境与区域发展、城市与区域、区际联系 |
| 选择性必修三 | 选必三 | 资源安全、生态环境安全、环境保护与绿色发展 |

### 3.2 高考真题时间跨度

**2012 年 — 2026 年**，共 15 年。

### 3.3 试卷类型

#### 3.3.1 旧高考阶段（2012—2020）

地理属于**文科综合**的一部分，不单独成卷。

| 时期 | 试卷名称 | 地理部分说明 |
|------|---------|------------|
| 2012-2020 | 全国文综卷 I（课标 I） | 地理选择题 + 综合题，约 100 分（全卷 300 分） |
| 2012-2020 | 全国文综卷 II（课标 II） | 同上 |
| 2012-2020 | 全国文综卷 III（课标 III） | 同上（2016 起） |
| 2012-2020 | 北京文综卷 | 自主命题，地理部分 |
| 2012-2020 | 天津文综卷 | 自主命题，地理部分 |
| 2012-2019 | 江苏地理卷 | 单独命题（江苏地理为独立试卷，非文综） |
| 2012-2019 | 上海地理卷 | 单独命题（上海地理等级考） |
| 2012-2019 | 海南地理卷 | 单独命题（海南地理为独立试卷） |

> **关键差异**：旧高考中文综卷的地理部分需要从整卷中提取，不是独立试卷。而江苏、上海、海南的地理是独立试卷。

#### 3.3.2 新高考阶段（2021—2026）

地理作为**选考科目**，各省独立命题或使用统一卷。

**覆盖范围：全国卷 + 主要省份**（不含所有 3+1+2 省份的全部年份）

| 时期 | 试卷名称 | 说明 |
|------|---------|------|
| 2021-2026 | 新高考 I 卷（地理） | 统一命题，部分省份使用 |
| 2021-2026 | 新高考 II 卷（地理） | 统一命题，部分省份使用 |
| 2021-2026 | 北京地理卷 | 自主命题 |
| 2021-2026 | 上海地理卷 | 自主命题（等级考） |
| 2021-2026 | 浙江地理卷 | 自主命题 |
| 2021-2026 | 天津地理卷 | 自主命题 |
| 2021-2026 | 江苏地理卷 | 自主命题 |
| 2021-2026 | 湖南/湖北/广东地理卷 | 3+1+2 模式代表性省份 |

> **范围说明**：v1 覆盖全国卷 + 教育大省/直辖市（北京、上海、浙江、天津、江苏、湖南、湖北、广东）。河北、辽宁、福建、重庆等其他 3+1+2 省份暂不覆盖，后续迭代补充。

> 预估 **150-250 套试卷**，每套 15-25 题，总计约 **3,000-5,000 道地理题目**。

### 3.4 数据量估算

| 维度 | 估算 |
|------|------|
| 旧高考（2012-2020） | ~150 套（全国文综 + 主要省份），每套地理 ~11 题，约 1,650 题 |
| 新高考（2021-2026） | ~150-200 套（全国卷 + 主要省份），每套 ~20 题，约 3,000-4,000 题 |
| **15 年总量** | **约 4,500-5,500 道地理题目** |

### 3.5 题型分类

| 题型 | 代码 | 说明 |
|------|------|------|
| 选择题 | `choice` | 单选（旧高考）/ 单选 + 不定项选择（新高考） |
| 综合题 | `comprehensive` | 需要文字作答的分析题，通常含多个小问 |
| 填空题 | `fill_blank` | 少量存在，主要出现在旧高考 |
| 选做题 | `elective` | 旧高考中的选修模块题（旅游地理 / 环境保护二选一） |

### 3.6 难度判定标准

| 难度 | 判定标准 | 典型位置 |
|------|---------|---------|
| `basic` | 单一知识点直接考查，读图/记忆为主 | 选择题前 4-6 题 |
| `medium` | 2-3 个知识点综合，需要分析推理 | 选择题后半段、综合题前 2 题 |
| `hard` | 多知识点深度综合，需要区域认知 + 空间思维 + 逻辑推理 | 压轴选择题、综合题最后一题 |

**综合题难度标记规则（v1）**：综合题含多个小问、各小问难度不同时，**整道大题以最高难度小问为准**统一标记。例如：一道综合题含 3 个小问（basic + medium + hard），整题标记为 `hard`。v2 可考虑支持子问独立难度。

## 4. 知识体系

### 4.1 知识点设计原则

1. **以人教版 2019 教材为骨架**，但不局限于教材章节划分
2. **自然地理 + 人文地理**双主线，反映学科内在结构
3. **粒度适中**：与 pep-math 的 94 个知识点相当，预估 80-100 个
4. **高考考点导向**：每个知识点对应高考中的具体考查内容
5. **跨版本兼容**：知识点命名不绑定特定教材版本，便于未来扩展

> **设计原则**：以 2017 课标 + 人教版 2019 教材为骨架，按高考高频考点拆分/合并。

> **与 v1.0 的 90 个相比的调整说明**（最终 74 个）：
> - 合并了过于细碎的知识点（如侵蚀地貌+堆积地貌→外力作用与常见地貌；喀斯特+海岸→合并为一个）
> - 合并了高考低频且内容重叠的知识点（如文化地理+民族宗教地理各自保留但缩减描述）

## 5. 数据模型设计

### 5.1 Schema：高考真题

```typescript
// 教材枚举（nceeSchema 和 knowledgePointSchema 共用）
const textbookEnum = z.enum([
  'required-1', 'required-2',
  'selective-1', 'selective-2', 'selective-3',
]);

const nceeSchema = z.object({
  type: z.literal('ncee'),
  ncee_id: z.string(),
  // 格式: ncee-{year}-{paper_code}-{question_number}
  // 例: ncee-2024-new-gao-kao-1-18
  // 例: ncee-2019-national-wenke-1-36（2019全国I卷文综地理第36题）
  year: z.number().int().min(2012).max(2026),
  paper: z.string(),              // e.g. "2024新高考I卷"
  paper_code: z.string().regex(
    /^\d{4}-[a-z0-9-]+$/,
    'paper_code 必须全小写，短横线分隔，格式: {year}-{type}-{suffix}'
  ),
  // e.g. "2024-new-gao-kao-1", "2019-national-wenke-1", "2022-beijing"
  question_number: z.number().int().min(1),
  question_type: z.enum(['choice', 'comprehensive', 'fill_blank', 'elective']),
  sub_type: z.string().optional(),  // "单选" / "不定项选择" / "旅游地理" / "环境保护"
  difficulty: z.enum(['basic', 'medium', 'hard']),
  // 综合题含多小问时，以最高难度小问为准（见 3.6 节规则）
  score: z.number().optional(),
  knowledge_points: z.array(z.string()).min(1),
  // ⚠️ 每个 ID 必须存在于 src/content/knowledge-points/ 目录中
  textbook_refs: z.array(z.object({
    textbook: textbookEnum,       // 与 knowledgePointSchema 共用同一枚举
    chapter: z.number().int().min(1),
    section: z.number().int().min(1).optional(),
  })).default([]),
  is_deprecated: z.boolean().default(false),
  // 废弃场景：录入错误、题目作废、版本迁移。废弃后页面显示提示横幅，不显示正文
  source: z.literal('高考真题'),
  region: z.string().optional(),
  // 文综卷中地理题的原始位置（旧高考专用）
  // 示例: "原文综卷第36题" / "原文综卷选做题43（旅游地理）"
  original_section: z.string().optional(),
  // ⚠️ 旧高考 (year <= 2020) 的必做/选做综合题此字段必填
  // ⚠️ 新高考 (year >= 2021) 不应填写此字段
  has_chart: z.boolean().default(false),
  chart_text_desc: z.string().optional(),
  // ⚠️ has_chart === true 时，chart_text_desc 必填（构建脚本校验）
  chart_files: z.array(z.string()).default([]),
  // SVG 文件路径列表，如 ["/svg/ncee/2024/new-gao-kao-1/q05-contour.svg"]
  // has_chart 为 true 时 chart_files 至少包含一个文件；为 false 时为空数组
  elective_group_id: z.string().optional(),
  // 旧高考选做题"二选一"关联标记
  // 同一套试卷的两道选做题填写同一个 elective_group_id
  // 例: "2019-national-wenke-1-elective" 表示第43题(旅游地理)和第44题(环境保护)为一组
  // UI 层面展示 "本题与 XX 题为二选一选做题"
});
```

### 5.1.1 真题 Markdown 正文格式规范

frontmatter 只存放元数据（上述 Zod schema 字段）。题干、答案、解析等内容写在 Markdown 正文中，遵循以下格式：

```markdown

type: ncee

# ... (frontmatter 字段)
---

**题目：**

阅读图文资料，完成下列要求。

![某区域等高线地形图](/svg/ncee/2024/new-gao-kao-1/q18-contour.svg)

该区域位于...（题干正文）

(2) 说明 XXX 对 XXX 的影响。（10 分）

**(1)** 第1步：...

第2步：...
```

**正文格式约束**：
- 题干以 `**题目：**` 开头
- 综合题各小问用 `(1)` `(2)` `(3)` 编号

### 5.4 ncee_id 全局唯一标识

格式：`ncee-{year}-{paper_code}-{question_number}`

示例：
- `ncee-2024-new-gao-kao-1-01` — 2024 新高考 I 卷第 1 题
- `ncee-2019-national-wenke-1-01` — 2019 全国 I 卷文综地理第 1 题（选择题）
- `ncee-2019-national-wenke-1-36` — 2019 全国 I 卷文综地理第 36 题（综合题）
- `ncee-2022-beijing-19` — 2022 北京卷第 19 题
- `ncee-2018-jiangsu-25` — 2018 江苏卷第 25 题

### 5.5 文综卷地理题的特殊处理

旧高考（2012-2020）中，全国文综卷的地理部分嵌入在文综卷内：

| 部分 | 题号范围 | 题型 |
|------|---------|------|
| 地理选择题 | 第 1-11 题（或类似） | 单选 |
| 地理必做综合题 | 第 36-37 题（或类似） | 综合分析 |
| 地理选做题 | 第 43 或 44 题 | 旅游地理 / 环境保护 |

**处理规则**：
- `question_number` 使用**地理部分内的编号**（1, 2, 3...），不使用文综卷的原始总题号
- `original_section` 标记该题在文综卷中的位置
- `paper_code` 使用 `national-wenke-1` / `national-wenke-2` / `national-wenke-3`
- `paper` 显示为 "2019全国I卷（文综地理部分）"

### 7.3.1 筛选器实现方案

**v1 方案：客户端 JS 筛选**

| 规则 | 说明 |
|------|------|
| 多条件逻辑 | **AND**（同时满足全部筛选条件） |
| URL 同步 | 筛选条件写入 query 参数，刷新保留、链接可分享。例：`/ncee?year=2024&difficulty=hard` |
| 知识点筛选 | 支持多选（知识点间为 OR 关系，即选中任一知识点的题目均显示） |
| 非法参数容错 | URL 中传入不存在的 `kp_id`、非法年份等 → 自动丢弃该参数，页面正常渲染 |
| 清空筛选 | 提供"清空全部筛选"按钮，一键重置 |
| 无结果 | 显示"未找到匹配的真题"提示，建议调整筛选条件 |

**技术实现**：页面加载时从构建脚本输出的分片 JSON 读取数据，客户端 JS 执行筛选逻辑。Astro 页面为纯静态 HTML，筛选通过 `<script>` 标签内联 JS 实现。

## 11. 风险与注意事项

### 11.1 版权

1. **参考答案必须原创**：禁止复制网络现成解析。PR 合并前需人工审核解析原创性
2. **禁止商业用途**：README + 页脚标注版权声明
3. **禁止图片扫描**：全部文字转录 + SVG 重绘，不复用试卷扫描件
4. **题目文本**：本项目仅用于个人学习教育用途，不用于商业分发；使用者自行承担文本使用合规风险
5. **SVG 示意图**：必须重新绘制简化示意图，禁止直接复刻教材原图，避免著作权风险

### 11.2 数据准确性

- 题目文本需与原始试卷一致
- 知识点分类需人工审核
- 教材关联需确认准确
- 旧高考文综卷中地理题的提取需仔细核对

### 11.3 规模管理

- 预估 4,500-6,500 道题，文件量巨大
- 使用并行 agent 按试卷粒度批量生成
- 构建脚本分片输出，避免 OOM
- 页面分页 + 懒加载

### 11.4 旧高考 vs 新高考

| 场景 | 处理方式 |
|------|---------|
| 旧高考文综卷 | 从文综卷中提取地理部分，`question_number` 使用地理内部编号 |
| 旧高考选做题 | 旅游地理和环境保护都录入，`sub_type` 标记 |
| 新高考独立卷 | 直接录入 |
| 部分省份过渡年份 | 确认该省该年使用全国卷还是自主命题 |

### 11.5 图表依赖

部分题目高度依赖地图/图表，纯文字描述可能不够充分。

**缓解策略**：
- 录入时尽量提取图表中的关键数据（数值、趋势、分布特征）
- 对于无法用文字充分描述的题目，在题目正文中注明"本题涉及示意图，请参考教材/原卷"
- 后续迭代可考虑添加 SVG 示意图库

### 12.1 补充说明

**填空题（fill_blank）处理**：新高考地理几乎无独立填空题。若综合题内部包含填空形式的小问，整题仍归类为 `comprehensive`，在正文中标注填空形式即可。`fill_blank` 类型仅用于旧高考中确实独立存在的填空题。

**is_deprecated 废弃场景**：
- 录入错误（题目文本/答案有误，需重新录入）
- 题目作废（重复录入、试卷信息错误）
- 版本迁移（知识点体系调整导致旧题无法正确关联）

废弃操作：将 frontmatter 中 `is_deprecated` 设为 `true`，保留文件（不删除），页面显示废弃横幅。

**低频知识点处理**：`cultural-geography`、`ethnicity-religion` 等低频知识点，只要高考真题中出现相关考查，正常录入关联。不因频率低而跳过。

### 14.3 仍需注意的风险

1. **SVG 录入成本**：含图表的题目占比高（预估 60-70%），SVG 制作耗时。建议：简单图表优先 SVG，复杂原图可用简化版 + 文字补充。Phase 2.5 性能验证时评估 SVG 数量对构建时间的影响。
2. **旧高考文综卷提取**：不同年份文综卷的地理题号位置不完全一致，需要逐年核对原始试卷。
3. **知识点与教材映射**：部分知识点跨多章多册，映射关系需仔细处理。
4. **选做题处理**：旧高考选做题两题都录入，`elective_group_id` 标记二选一关系。
5. **新高考省份卷数量**：即使只覆盖主要省份，2021-2026 每年 ~25 套，6 年 ~150 套，工作量不小。严格按 Phase 分批执行。
